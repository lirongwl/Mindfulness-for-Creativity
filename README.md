# Mindfulness for Creativity 🧘‍♂️💡

This repository contains the data and analysis pipelines for our study investigating the impact of mindfulness meditation (Focused Attention and Open Monitoring) on the creative performance (convergent thinking) of scientific researchers. 

By combining behavioral tests, psychological scales, and high-density EEG, we aim to uncover the neural mechanisms behind meditation-induced cognitive enhancement.

## 📂 Repository Structure

* **`01_Behavioral_Data/`**: Pre- and post-intervention creativity test results (e.g., Remote Associates Test scores, reaction times).
* **`02_Psychological_Data/`**: Baseline and post-training psychological assessments (e.g., trait mindfulness, anxiety, depression scales).
* **`03_EEG_Raw_and_Pipeline/`**: Raw continuous EEG recordings and automated MATLAB/EEGLAB processing scripts (filtering, ICA, etc.).
* **`04_Publications/`**: Fully processed derivative datasets and specific scripts used to generate figures and statistics for our published papers.

## 🚀 Quick Start

* **To reproduce paper results:** Navigate to `04_Publications/` to find the specific scripts and processed data for our manuscripts.
* **To explore neural data:** Check `03_EEG_Raw_and_Pipeline/` for raw data and our standardized preprocessing pipelines.
